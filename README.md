# cleanup-node-modules

windows向け：一定期間（14日）更新していないプロジェクトのnode_modulesを削除する<br>
https://note.affi-sapo-sv.com/cleanup-node-modules.php<br>
フォルダ内のプロジェクトからnode_modulesを検索して、プロジェクト内のファイルを14日以上更新していないときnode_modulesを削除する。

---

## 使用方法

1) 全てのファイルをフォルダ内に配置<br>
2) check_node_modules.batを実行して、削除候補のnode_modulesを確認<br>
3) cleanup_node_modules.batでnode_modulesを削除<br>
